# 专属故事共创后端接口契约

## 1. 文档定位

本文档定义“专属故事共创创建流程”的后端接口契约，用于承接 `14-专属故事共创创建流程UI执行方案.md` 中确认的产品体验。

目标不是新增一个普通表单提交接口，而是把创建过程拆成可恢复、可编辑、可追踪的共创会话：

```text
想法 -> 理解与素材 -> 方向 -> 大纲 -> 生成 -> 验收
```

后端需要承担三件事：

- 真实理解用户输入，而不是由前端模板拼方向。
- 真实提取和保存专属素材，而不是只做前端展示标签。
- 把用户选择的方向、补充素材和高级画面偏好带入后续生成。

默认 API 前缀沿用项目现有约定：

```text
/api
```

统一返回 envelope 沿用现有后端契约：

```json
{ "data": {} }
```

统一错误：

```json
{
  "error": {
    "code": "validation_error",
    "message": "故事想法至少需要 8 个字符",
    "field": "quick_idea"
  }
}
```

## 2. 核心资源

### 2.1 StorybookCreationSession

创建绘本过程中的共创会话。它不是最终绘本，而是最终 `Storybook` 生成前的草稿容器。

建议字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 会话 ID |
| `workspace_id` | string | 所属空间 |
| `created_by` | string | 创建人 |
| `status` | enum | 当前流程状态 |
| `quick_idea` | string | 用户原始一句话想法 |
| `understanding` | object | AI 对用户想法的理解 |
| `materials` | array | AI 识别和用户补充的专属素材 |
| `directions` | array | AI 生成的故事方向 |
| `selected_direction_id` | string/null | 用户选择的方向 |
| `outline` | object/null | 故事大纲 |
| `visual_preferences` | object | 画面偏好 |
| `storybook_id` | string/null | 生成后的正式绘本 ID |
| `last_job_id` | string/null | 最近一次生成任务 ID |
| `idempotency_key` | string/null | 最近一次正式绘本生成幂等键 |
| `requires_understanding_refresh` | boolean | 基础输入修改后，理解是否过期 |
| `requires_direction_refresh` | boolean | 素材或理解修改后，方向是否过期 |
| `requires_outline_refresh` | boolean | 方向、素材或页数修改后，大纲是否过期 |
| `created_at` | string | 创建时间 |
| `updated_at` | string | 更新时间 |

### 2.2 CreationUnderstanding

AI 对用户原始想法的结构化理解。

```json
{
  "summary": "为 4 岁的乐乐创作一本关于分享红色小汽车的温柔成长故事。",
  "target_user": "parent",
  "goal": "帮助孩子理解分享和轮流",
  "tone": "温柔、鼓励、不说教",
  "scene": "家庭共读",
  "age_group": "4-5 岁"
}
```

### 2.3 CreationMaterial

专属素材。来源可以是 AI 提取，也可以是用户手动补充。

```json
{
  "id": "mat_1",
  "label": "红色小汽车",
  "type": "object",
  "source": "ai_extracted",
  "confidence": 0.91,
  "locked": false
}
```

字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 素材 ID |
| `label` | string | 展示名称 |
| `type` | enum | `character/object/place/event/theme/emotion/custom` |
| `source` | enum | `ai_extracted/user_added/system` |
| `confidence` | number/null | AI 识别置信度，用户补充可为空 |
| `locked` | boolean | 是否强制带入后续生成 |

`locked=true` 表示后端生成方向、大纲、角色和分页时必须尽量使用该素材；如果模型无法合理使用，返回的 `review_points` 或生成任务 `last_error` 中必须说明原因。用户补充素材默认 `locked=true`，AI 识别素材默认可由后端根据置信度决定是否锁定。

### 2.4 StoryDirection

故事方向。后端应返回真正基于用户输入和素材生成的 3 个方向。

```json
{
  "id": "dir_1",
  "title": "乐乐的小小分享练习",
  "summary": "从红色小汽车的一次轮流开始，让乐乐在被理解中慢慢尝试分享。",
  "fit_reason": "适合情绪安抚和家庭共读",
  "personal_hook": "把红色小汽车放在乐乐第一次愿意尝试轮流的关键时刻。",
  "material_ids": ["mat_1", "mat_2"],
  "tone": "gentle"
}
```

### 2.5 CreationOutline

生成完整绘本前的大纲。

```json
{
  "summary": "一本关于乐乐学习分享红色小汽车的温柔故事。",
  "pages": [
    {
      "page_number": 1,
      "summary": "乐乐抱着红色小汽车来到星星班。",
      "material_ids": ["mat_1", "mat_2"]
    }
  ],
  "review_points": [
    "是否保留乐乐和红色小汽车",
    "是否避免说教",
    "是否适合 4-5 岁孩子共读"
  ]
}
```

### 2.6 VisualPreferences

画面偏好。它是面向用户的偏好，不应暴露模型参数。

```json
{
  "style": "watercolor",
  "page_aspect_ratio": "portrait_4_5",
  "visual_complexity": "simple",
  "character_consistency": "auto"
}
```

字段枚举建议：

| 字段 | 可选值 |
| --- | --- |
| `page_aspect_ratio` | `portrait_4_5` / `square_1_1` / `landscape_16_9` |
| `visual_complexity` | `simple` / `standard` / `rich` |
| `character_consistency` | `auto` / `speed` / `confirm_character` |

## 3. 状态机

### 3.1 CreationSessionStatus

```text
draft
understanding_ready
directions_ready
direction_selected
outline_ready
generating
storybook_ready
failed
abandoned
```

### 3.2 状态流转

| 当前状态 | 触发动作 | 下一状态 | 说明 |
| --- | --- | --- | --- |
| `draft` | 创建会话并完成理解 | `understanding_ready` | 已有理解和素材 |
| `understanding_ready` | 生成方向 | `directions_ready` | 已有 3 个方向 |
| `directions_ready` | 用户选择方向 | `direction_selected` | 锁定方向 |
| `direction_selected` | 生成大纲 | `outline_ready` | 已有页级大纲 |
| `outline_ready` | 一键生成整本 | `generating` | 创建生成任务 |
| `generating` | 任务成功 | `storybook_ready` | 已生成正式绘本 |
| `generating` | 任务失败 | `failed` | 可重试 |
| `failed` | 用户重试最近任务 | `generating` | 复用原会话上下文 |
| `failed` | 用户修改输入或素材 | `draft` / `understanding_ready` | 根据修改范围清理下游结果 |
| 任意非终态 | 用户放弃 | `abandoned` | 不删除历史 |

### 3.3 状态约束

- 未达到 `directions_ready` 时不能选择方向。
- 未达到 `direction_selected` 时不能生成大纲。
- 未达到 `outline_ready` 时不能一键生成整本。
- `generating` 状态下再次调用生成接口必须返回当前 `job_id/storybook_id`，不得创建重复绘本。
- 已经 `storybook_ready` 的会话不应再次生成同一本；若用户修改想法或素材，应创建新会话或明确执行重新生成。

## 4. 接口清单

### 4.1 共创会话

| Method | Path | 用途 |
| --- | --- | --- |
| `POST` | `/api/workspaces/:workspace_id/storybook-creation-sessions` | 创建共创会话，并完成初始理解 |
| `GET` | `/api/workspaces/:workspace_id/storybook-creation-sessions` | 查询当前空间共创会话列表，用于草稿箱和跨设备恢复 |
| `GET` | `/api/workspaces/:workspace_id/storybook-creation-sessions/latest` | 查询最近一个未完成共创会话，用于继续上次编辑 |
| `GET` | `/api/workspaces/:workspace_id/storybook-creation-sessions/:session_id` | 查询会话详情，用于刷新恢复 |
| `PATCH` | `/api/workspaces/:workspace_id/storybook-creation-sessions/:session_id` | 更新基础输入，例如故事想法、年龄、场景 |
| `POST` | `/api/workspaces/:workspace_id/storybook-creation-sessions/:session_id/abandon` | 放弃会话 |

### 4.2 理解与素材

| Method | Path | 用途 |
| --- | --- | --- |
| `POST` | `/api/workspaces/:workspace_id/storybook-creation-sessions/:session_id/understanding:refresh` | 重新理解用户输入并刷新素材 |
| `PATCH` | `/api/workspaces/:workspace_id/storybook-creation-sessions/:session_id/materials` | 增删改专属素材 |

### 4.3 故事方向

| Method | Path | 用途 |
| --- | --- | --- |
| `POST` | `/api/workspaces/:workspace_id/storybook-creation-sessions/:session_id/directions:generate` | 生成或换一批故事方向 |
| `POST` | `/api/workspaces/:workspace_id/storybook-creation-sessions/:session_id/direction` | 选择故事方向 |

### 4.4 大纲

| Method | Path | 用途 |
| --- | --- | --- |
| `POST` | `/api/workspaces/:workspace_id/storybook-creation-sessions/:session_id/outline:generate` | 基于已选方向生成大纲 |
| `PATCH` | `/api/workspaces/:workspace_id/storybook-creation-sessions/:session_id/outline/pages/:page_number` | 调整单页大纲 |
| `PATCH` | `/api/workspaces/:workspace_id/storybook-creation-sessions/:session_id/outline` | 批量保存大纲 |

### 4.5 画面偏好与生成

| Method | Path | 用途 |
| --- | --- | --- |
| `PATCH` | `/api/workspaces/:workspace_id/storybook-creation-sessions/:session_id/visual-preferences` | 保存画面偏好 |
| `POST` | `/api/workspaces/:workspace_id/storybook-creation-sessions/:session_id/storybook:generate` | 一键生成正式绘本草稿 |

## 5. 接口详情

### 5.1 创建共创会话


用途：

- 用户在“想法”页点击 `开始生成方向`。
- 后端保存原始想法。
- 后端调用 AI 完成理解和素材提取。
- 第一版可以同步返回理解结果；如果耗时较长，也可以返回 `job_id` 并轮询。

```json
  "page_aspect_ratio": "portrait_4_5",
  "visual_complexity": "simple",
  "character_consistency": "auto"
```

### 5.2 查询共创会话列表

```http
GET /api/workspaces/:workspace_id/storybook-creation-sessions
```

用途：

- 草稿箱展示。
- 前端丢失 `session_id` 后，根据当前用户和空间找回未完成会话。
- 园所管理员查看园所空间内的创建草稿。

Query:

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `status` | `active` | `active/all/draft/understanding_ready/directions_ready/direction_selected/outline_ready/generating/storybook_ready/failed/abandoned` |
| `created_by` | 当前用户 | `school_admin` 可传用户 ID；普通成员只能查自己 |
| `limit` | 20 | 最大 50 |
| `offset` | 0 | 分页偏移 |

`status=active` 表示排除 `storybook_ready/abandoned`，返回仍可能继续编辑的会话。

Response:

```json
{
  "data": [
    {
      "id": "cs_01JABC",
      "status": "outline_ready",
      "quick_idea": "给 4 岁的乐乐...",
      "understanding_summary": "为 4 岁的乐乐创作一本关于分享红色小汽车的温柔成长故事。",
      "selected_direction_title": "乐乐的小小分享练习",
      "storybook_id": null,
      "updated_at": "2026-08-14T10:05:00Z"
    }
  ],
  "meta": {
    "total": 1,
    "limit": 20,
    "offset": 0,
    "has_more": false
  }
}
```

### 5.7 增删改专属素材

```http
PATCH /api/workspaces/:workspace_id/storybook-creation-sessions/:session_id/materials
```

用途：

- 用户点击 `加入素材`。
- 用户删除错误素材。
- 用户把某个素材设为必须使用。
- 本接口使用操作列表语义，避免“没传的素材到底删除还是保留”的歧义。

Request:

```json
{
  "operations": [
    {
      "op": "add",
      "label": "星星班",
      "type": "place",
      "locked": true
    },
    {
      "op": "update",
      "id": "mat_2",
      "locked": true
    },
    {
      "op": "remove",
      "id": "mat_4"
    }
  ]
}
```

操作规则：

| op | 必填字段 | 说明 |
| --- | --- | --- |
| `add` | `label` | 新增用户补充素材，默认 `source=user_added`、`locked=true` |
| `update` | `id` | 更新 `label/type/locked`，不得修改 `source/confidence` |
| `remove` | `id` | 删除素材；如果素材已被方向或大纲引用，后端返回刷新标记 |

Response:

```json
{
  "data": {
    "id": "cs_01JABC",
    "status": "understanding_ready",
    "materials": [
      {
        "id": "mat_1",
        "label": "乐乐",
        "type": "character",
        "source": "ai_extracted",
        "confidence": 0.94,
        "locked": true
      },
      {
        "id": "mat_3",
        "label": "星星班",
        "type": "place",
        "source": "user_added",
        "confidence": null,
        "locked": true
      }
    ],
    "requires_direction_refresh": true,
    "requires_outline_refresh": true,
    "updated_at": "2026-08-14T10:06:00Z"
  }
}
```

## 6. 异步任务契约

### 6.1 P0 同步与异步边界

为了降低第一阶段实现复杂度，P0 建议这样划分：

| 能力 | P0 返回方式 | 原因 |
| --- | --- | --- |
| 创建会话与理解 | 同步返回 | 首屏反馈需要快，失败后用户仍在想法页 |
| 生成方向 | 同步返回 | 方向选择是下一步入口，3 个方向响应体较小 |
| 生成大纲 | 同步返回 | 大纲用于确认，通常只有 6-8 页摘要 |
| 一键生成正式绘本 | 异步返回 `job_id` | 会创建绘本、角色、分页、插图，耗时长 |

如果后续模型耗时变长，理解、方向、大纲也可以改为异步，但必须沿用本节 job 契约，不改变前端状态语义。

### 6.2 共创流程 Job Type

如果使用现有 `GenerationJob` 承接共创流程，新增或约定以下 `job_type`：

| job_type | 触发接口 | 成功后写回 |
| --- | --- | --- |
| `creation_understanding` | `POST /understanding:refresh` 或创建会话 | `understanding/materials/status=understanding_ready` |
| `creation_directions` | `POST /directions:generate` | `directions/status=directions_ready` |
| `creation_outline` | `POST /outline:generate` | `outline/status=outline_ready` |
| `creation_storybook_generate` | `POST /storybook:generate` | `storybook_id/status=storybook_ready` |

`GenerationJob.input_json` 至少包含：

```json
{
  "creation_session_id": "cs_01JABC",
  "quick_idea": "给 4 岁的乐乐...",
  "materials": [],
  "selected_direction": {},
  "outline": {},
  "visual_preferences": {},
  "idempotency_key": "8c6d06c7-4131-4c4b-a8ed-4b47c6ad2b1b"
}
```

`GenerationJob.output_json` 成功时按 job type 返回对应结构：

```json
{
  "schema_version": "creation.provider.v1",
  "provider": "deepseek",
  "mode": "real",
  "creation_session_id": "cs_01JABC",
  "understanding": {},
  "materials": [],
  "directions": [],
  "outline": {},
  "storybook_id": "book_01JABC"
}
```

前端轮询规则：

- `POST /storybook:generate` 返回 `job_id` 后，前端可以轮询现有 `GET /generation-jobs/:job_id`。
- 每次 job 成功或失败后，前端应再读取 `GET /storybook-creation-sessions/:session_id`，以会话状态作为最终页面状态来源。
- job 失败时，会话进入 `failed`，并写入 `last_job_id`；前端展示失败信息和重试入口。

### 6.3 失败与重试

- `creation_storybook_generate` 失败后，不删除已创建的 `Storybook` 草稿；如果已有 `storybook_id`，会话保留该 ID，便于后续重试补齐缺失内容。
- 重试优先复用现有 `POST /generation-jobs/:job_id/retry`。
- 如果重试需要重新组装上下文，也可以再次调用 `POST /storybook:generate`，但必须带同一个 `idempotency_key` 或由后端返回已有 `storybook_id/job_id`。
- `failed` 状态下用户修改基础输入、素材、方向或大纲时，应清理对应下游结果，并返回刷新标记。

## 7. CreationSession 到 Storybook 的映射

`POST /storybook:generate` 创建正式绘本时，必须明确把共创会话字段写入 `Storybook`、`StorybookRole`、`StorybookPage` 和生成任务输入。

### 7.1 Storybook 映射

| Storybook 字段 | 来源 |
| --- | --- |
| `title` | 优先使用 `selected_direction.title`，否则从 `understanding.summary` 生成短标题 |
| `type` | 默认 `regular`；如果后续绑定儿童档案，可为 `customized` |
| `age_group` | `understanding.age_group` 或创建请求 `age_group` |
| `use_scene` | `understanding.scene` 或创建请求 `use_scene` |
| `teaching_goal` | `understanding.goal` |
| `cover_tone` | `visual_preferences.style` |
| `page_aspect_ratio` | `visual_preferences.page_aspect_ratio` |
| `teacher_review_status` | `pending` |
| `status` | 初始 `editing`，所有必需插图完成且质量通过后再进入 `exportable` |

建议额外在 `Storybook` 的扩展元数据或审计日志中记录：

```json
{
  "creation_session_id": "cs_01JABC",
  "selected_direction_id": "dir_1",
  "materials": [],
  "personal_hook": "把红色小汽车放在乐乐第一次愿意尝试轮流的关键时刻。",
  "visual_preferences": {}
}
```

### 7.2 StorybookRole 映射

- `materials.type=character` 应优先转为主角、同伴或老师角色。
- `materials.type=object/place` 不一定生成角色，但必须进入相关页面的 `illustration_prompt`。
- 如果 `character_consistency=confirm_character`，P0 不新增阻断式角色确认接口；后端仍生成角色和参考图，前端在验收工作台中处理重画或编辑。
- P1 如果要做插图前确认主角形象，再新增角色预览接口。

### 7.3 StorybookPage 映射

每个 `outline.pages[]` 至少生成一个 `StorybookPage`：

| StorybookPage 字段 | 来源 |
| --- | --- |
| `page_number` | `outline.pages[].page_number` |
| `title` | 根据页摘要生成，不超过 30 字 |
| `body` | 基于页摘要扩写成适龄文本 |
| `illustration_prompt` | 页摘要 + 引用素材 + 方向 personal_hook + visual_preferences |
| `status` | 文本就绪但未生成图时为 `needs_regeneration` 或项目现有等价状态 |

`illustration_prompt` 必须显式带入：

- 当前页 `material_ids` 对应素材。
- `selected_direction.personal_hook`。
- `visual_preferences.style/page_aspect_ratio/visual_complexity/character_consistency`。

### 7.4 生成完成后的验收状态

- 正式绘本生成后进入现有验收工作台。
- `Storybook.quality` 继续沿用现有详情接口派生。
- `teacher_review_status` 默认为 `pending`。
- 后续分页、角色或插图被修改时，沿用现有规则重置老师复核状态。

## 8. 权限规则

- 所有接口都要求登录。
- `workspace_id` 必须属于当前用户可访问空间。
- `personal_owner` 可以创建和管理自己个人空间下的会话。
- `school_admin` 可以查看和管理园所空间下所有会话。
- `school_teacher` 可以创建会话；默认只能查看自己创建的会话，除非后续增加协作权限。
- 平台运营不应通过普通工作区接口读取用户原始创作内容；如需排查，走运营审计和脱敏日志。

## 9. 校验规则

### 9.1 创建会话

- `quick_idea` 必填。
- `quick_idea` 去空格后至少 8 个字符。
- `quick_idea` 最大 2000 字符。
- `page_count` 默认 6，最小 4，最大 12。
- `age_group` 最大 40 字符。
- `use_scene` 最大 80 字符。
- `style` 必须是前后端约定的画风值，或作为自由文本保存在 `custom_style`。

### 9.2 素材

- `label` 必填，最大 40 字符。
- 单个会话最多 20 个素材。
- `type` 不识别时落为 `custom`。
- 用户补充素材默认 `locked=true`。
- `PATCH /materials` 必须使用 `operations[]`；不支持隐式全量替换，除非请求显式增加 `mode=replace`。
- `remove` 删除被方向或大纲引用的素材时，后端不得静默保留旧引用；必须返回刷新标记。
- 删除素材后，如果已有方向或大纲，应返回 `requires_direction_refresh=true` 或 `requires_outline_refresh=true`。

### 9.3 方向

- `direction_count` 默认 3，最小 1，最大 5；前端主流程只展示 3 个。
- 每个方向必须包含 `title/summary/fit_reason/personal_hook/material_ids`。
- `personal_hook` 不能为空；如果没有明确素材，必须说明“围绕用户原始想法中的真实细节”。

### 9.4 大纲

- `page_count` 必须与会话页数一致，除非请求显式覆盖。
- 每页必须有 `page_number/summary`。
- 页码从 1 开始连续。
- 每页摘要最大 200 字符。

### 9.5 生成正式绘本

- 会话状态必须至少为 `outline_ready`。
- 必须存在 `selected_direction_id`。
- 必须存在大纲。
- `idempotency_key` 必填。
- `generating/storybook_ready` 状态下重复调用不得创建第二本绘本。
- P0 阶段 `character_consistency=confirm_character` 不新增阻断式角色确认；仍生成整本，用户在验收工作台调整角色和插图。

## 10. 错误模型

沿用现有错误 envelope。

| code | 场景 |
| --- | --- |
| `unauthorized` | 未登录或 token 无效 |
| `forbidden` | 无权访问该 workspace 或会话 |
| `not_found` | 会话不存在或不属于当前空间 |
| `validation_error` | 字段缺失、格式不合法 |
| `state_conflict` | 当前状态不允许该动作 |
| `generation_failed` | AI 生成失败 |
| `provider_unavailable` | 真实生成 provider 未配置或暂不可用 |
| `rate_limited` | 触发生成频率限制 |

示例：

```json
{
  "error": {
    "code": "state_conflict",
    "message": "请先选择故事方向，再生成大纲",
    "field": "selected_direction_id"
  }
}
```


## 14. 开放问题与当前决策

1. 是否需要会话列表接口？
   - 当前决策：需要，但不是 P0。
   - P1 提供 `GET /storybook-creation-sessions` 和 `GET /storybook-creation-sessions/latest`。

2. 方向和大纲生成是否同步返回？
   - 当前决策：P0 同步返回。
   - 如果真实模型耗时较长，按第 6 节异步任务契约返回 `job_id`，最终状态仍以 creation session 为准。

3. `character_consistency=confirm_character` 是否要插入额外确认步骤？
   - 当前决策：P0 不插入额外步骤，避免破坏一键生成流畅性。
   - 高定制场景 P1/P2 再设计角色预览确认接口。

4. 素材是否需要独立表？
   - MVP 可以放在 creation session JSON 中。
   - 后续如果要分析用户素材、复用人物/IP/品牌资产，应拆成独立资源。

5. 会话完成后是否允许继续修改？
   - 建议不直接修改已完成会话。
   - 修改已生成绘本应走绘本详情页编辑和重绘流程。

6. 是否需要独立角色预览确认接口？
   - 当前决策：P0 不需要。
   - 后续如要支持高定制，可新增 `GET /storybook-creation-sessions/:id/character-preview`、`POST /character-preview:confirm` 和 `POST /character-preview:regenerate`。
