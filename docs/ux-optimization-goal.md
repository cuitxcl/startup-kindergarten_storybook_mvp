# 绘本产品 UX 优化 · 执行目标

> 目标：让页面展示**简洁**、操作**高效**、体验**流畅**。
> 范围：纯前端重排，不改后端接口与数据模型。
> 涉及页面：绘本详情页、生成向导、绘本列表、工作台。

---

## 一、总目标（Definition of Done）

1. 详情页任何状态下，头部操作 ≤ 3 个可见按钮（1 主 + 1 次 + 「⋯更多」）。
2. 详情页内容区合并为 2 个区块（本页工作台 / 交付），其余默认折叠。
3. 向导级联生成期间有明确的步骤进度指示，且生成中锁定需求表单与步骤导航。
4. 绘本列表卡片操作与状态对齐，每张卡可见操作 ≤ 2 个 + 「⋯」入口。
5. 全局操作反馈统一为轻提示（toast），阻断信息才用 Notice。
6. 关键加载/生成过程有骨架占位，页面无明显跳动。

---

## 二、批次拆解与验收标准

### 批次 1：详情页收敛（最大降噪）

**改动范围**：`StorybookDetailPage.tsx`、`styles.css`

| # | 任务 | 验收标准 |
|---|------|---------|
| 1.1 | 头部操作按状态收敛 | 编辑中：主「继续处理分页」+ 次「标记可交付」；可交付：主「导出 PDF」+ 次「分享」；其余（管理角色/编辑信息/复制副本/删除）收进「⋯更多」菜单，删除在菜单底部且红色 |
| 1.2 | 内容区合并 | 「当前页检查 + 插图区 + 角色参考图」合并为「本页工作台」；「质量结论 + 导出/分享记录」合并为「交付」；生成记录等其余卡片默认折叠（details 模式） |
| 1.3 | 回归验证 | `npx tsc --noEmit && npm run build` 通过；原有功能（重绘、AI 重写、导出、分享、删除）在菜单/新区块内均可达 |

### 批次 2：向导流畅度

**改动范围**：`NewStorybookPage.tsx`

| # | 任务 | 验收标准 |
|---|------|---------|
| 2.1 | 级联生成进度条 | 方案重生成时显示「方案 ✓ → 角色 ⏳ → 分页 ○」进度指示，随任务推进实时更新 |
| 2.2 | 生成中锁定 | 生成进行中：步骤导航、「上一步」、需求表单禁用，提示「生成完成后可继续编辑」 |
| 2.3 | 手动修改预期提示 | 方案/角色/分页的编辑区下方固定提示「修改在重新生成时生效；离开页面前请重新生成」 |

### 批次 3：列表与工作台降噪

**改动范围**：`StorybookListPage.tsx`、`DashboardPage.tsx`

| # | 任务 | 验收标准 |
|---|------|---------|
| 3.1 | 卡片信息降噪 | 教学目标单行截断；来源并入 meta 行；「最近任务」仅在失败/生成中时显示；阻断条件合并为一句高亮 |
| 3.2 | 卡片操作状态化 | 可交付卡主操作「导出」、草稿/待确认卡「继续完成」；删除收进卡片右上「⋯」 |
| 3.3 | 工作台聚焦卡动作化 | 副标题改为动作语言，如「还差一步：生成角色与道具」 |

### 批次 4：全局顺滑度

**改动范围**：`components/ui.tsx`（toast）、`styles.css`、各页面接入

| # | 任务 | 验收标准 |
|---|------|---------|
| 4.1 | 统一 toast | 成功类反馈（保存、删除、清理、复制）统一右上角轻提示，2.5s 自动消失；Notice 仅保留阻断/需处理场景 |
| 4.2 | 骨架占位 | 详情页切换分页、生成插图、列表「继续加载」时展示骨架，版面不跳动 |

| M2 | 批次 2 上线 | 级联生成有进度条且流程锁定，构建通过 |
| M3 | 批次 3 上线 | 卡片与工作台信息降噪完成，构建通过 |
| M4 | 批次 4 上线 | toast 统一 + 骨架占位，整体验收走查通过 |

## 四、约束与风险

- **不改后端**：所有优化为前端展示层重排，不动接口、不改数据模型。
- **功能不丢**：收敛进菜单/折叠区的功能必须保持可达，原有 disabledHint、状态徽章逻辑全部保留。
- **并行改动**：仓库中有用户未提交的并行改动，编辑时只碰必要行，不整段覆盖。
- **验证方式**：每批次 `npx tsc --noEmit && npm run build`；涉及生成链路的批次需实际跑一遍向导验证。
